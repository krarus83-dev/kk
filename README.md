# Маркет на React

Демонстрационный магазин: 100 товаров, поиск, категории, корзина и три языка. Изображения встроены в каталог. Оформление заказа и оплата не подключены.

Выбор языка меняет валюту: русский — рубли, узбекский — сумы, английский — доллары. Цены пересчитываются по условным фиксированным курсам: 1 USD = 90 RUB и 1 USD = 12 500 UZS. Это не актуальные курсы, они не обновляются автоматически.

Готовая автономная версия: `dist/market-react.html`.

Для изменения исходного кода установите Node.js, запустите `npm install`, затем `npm run build`. Результат появится в `dist/market-react.html`. Основной компонент — `src/App.jsx`, стили — `src/style.css`, каталог — `src/products.json`.
